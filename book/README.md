# Meaning by Design: A Practical Mini Textbook

This guide explores how ordinary products, messages, and interfaces gain meaning. It begins with persuasion, adds brand archetypes and visual language, and ends by showing how the three lenses can direct AI-assisted creative and technical work.

The recurring plain white T-shirt keeps the ideas concrete. Across the chapters, the same basic object becomes a useful test case for asking how audience, story, design, and decision-making work together.

## How to Use This Guide

Read the chapters in order the first time. Each chapter introduces a lens that the next chapter uses. As you read, compare the examples with a product or project of your own. Notice what changes when the object stays the same but the intended response, identity, or visual language changes.

The final chapter turns the ideas into a workflow for bounded AI-assisted work. Use it when you need to write a specification, review generated output, or decide what should remain a human responsibility.
